# Logos de Empresas de Testimonios

Coloca aquí los logos de las empresas de los clientes con los siguientes nombres:
- `vegroup.png` (o `.jpg`, `.svg`, `.webp`)
- `stability.png` (o `.jpg`, `.svg`, `.webp`)
- `alfa-club.png` (o `.jpg`, `.svg`, `.webp`)

*Nota: Mientras no se cargue la imagen, el sistema mostrará automáticamente un badge estilizado con las iniciales de la empresa (VG, ST, AC).*
